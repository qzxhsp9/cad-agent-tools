# 从 v0.4 迁移到 v0.5

删除旧配置中的以下内容：

- `.venv/Scripts/cad-agent-tools.exe` 绝对路径；
- `CAD_BACKEND=mock`；
- `D:/CADCases`；
- `D:/CADAgentJobs`；
- `CAD_INSPECT_EXE`。

替换为：

```json
{
  "mcpServers": {
    "cad-agent-tools": {
      "command": "uvx",
      "args": ["cad-agent-tools@0.5.0"]
    }
  }
}
```

v0.5 的基础检查完全在 Python 包内部运行。后续 OCCT 能力应以可选 Python 插件或平台专用原生 Wheel 提供，而不是要求普通用户手写本地 exe 路径。
